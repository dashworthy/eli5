# Recap

"I updated three form types and added tests" tells the user nothing they can check. Show what is different and how to see it.

First read `../../shared/board.md` (relative to this skill's base directory) for how to build and hand over the board. This file only says what goes on it.

## Information to supply

1. **What changed for users**: one sentence.
2. **Before / after**: the user-facing flow before and after, changed steps highlighted.
3. **See it yourself**: numbered steps to watch it work (URL, what to click, what you should see), 5 at most.
4. **Proof**: the tests that cover it and whether they pass, with the command to run them.
5. **Not done**: anything left open, follow-ups, or known limits.

## Board layout

- Takeaway line: what changed, 10 words or fewer.
- Section "Before" and section "After" side by side, flows lined up.
- Bottom row: See it yourself (numbered list), Proof, Not done.

## Hand over

Board link on its own line, then 2 to 3 lines: what now works, and the first "see it yourself" step.
